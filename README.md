# Lean POC Control Plane

Public, credential-isolated control plane for GitHub-first Lean POC generation.

The reusable discovery/generation contract remains owned by the private `mriekki/lean-poc-bootstrap` repository. This repository contains only the public request/orchestration surface and must not contain POC product definitions, GitHub App private keys, personal access tokens, or other credentials.

Operational status: bootstrap shell only. The multi-owner generation workflow is being added through a reviewed pull request before this control plane is considered active.
